# LaTeX導入講座

研究室に配属された学生が、環境構築から基本的な文書作成まで自力で進められることを目標とした入門教材です。

[**サイトを見る →**](https://ohige0831.github.io/latex-course/)

## 概要

TeX Live と Visual Studio Code を使って LaTeX 環境を構築し、日本語文書・数式・図表・参考文献の書き方を学べる入門教材です。Windows ユーザー向けにステップごとに解説しています。

## 対象読者

- 研究室に配属されたばかりで LaTeX を初めて使う学生
- 先輩や指導教員に頼らず環境構築を進めたい方
