## インストーラーが起動しない

### 症状

`install-tl-windows.bat` をダブルクリックしても何も起きない、またはすぐに閉じる。

### 考えられる原因

- 管理者権限がない
- セキュリティソフトがブロックしている
- ファイルのダウンロードが途中で壊れた

### まず試してください

1. ファイルを**右クリック**し、「**管理者として実行**」を選ぶ
2. 「このアプリがデバイスに変更を加えることを許可しますか？」と表示されたら「**はい**」を押す
3. それでも起動しない場合は、セキュリティソフトの設定で一時的にスキャンを停止してから再実行する

::: warning ウイルス対策ソフトについて
インストール完了後はセキュリティソフトを必ず有効に戻してください。

### 解決しない場合

- 別のブラウザでインストーラーをダウンロードし直す
- ダウンロードしたファイルを別のフォルダー（例：デスクトップ）に移してから実行する

## インストールが終わらない・ダウンロードが遅い

### 症状

インストールを始めて1時間以上たっても進捗が動いていない、またはダウンロードが非常に遅い。

### 考えられる原因

- TeX Live は数 GB あるため、30〜90 分かかるのは**正常**
- インターネット接続が不安定
- ダウンロード元サーバー（ミラー）の速度が遅い

### まず試してください

1. **まず30〜90分は待つ**。進捗バーが動いていれば正常です
2. 進捗が完全に止まって1時間以上変化がない場合は、インストーラーを終了して再起動する

::: tip インストール中にできること
TeX Live のインストール中は他の作業ができます。完了を待つ間に VS Code をインストールしておくのがおすすめです。
:::

### 解決しない場合

インストーラーの設定画面でダウンロード元（ミラー）を変更すると速くなる場合があります。日本国内のミラーを選ぶと、通常より速くなります。

## `latex` コマンドが見つからない・PATHが認識されない

### 症状

コマンドプロンプトで `latex --version` と入力すると、「`latex` は内部コマンドまたは外部コマンド…として認識されていません」と表示される。

### 考えられる原因

- インストール直後はPCの再起動が必要
- TeX Live のインストール先がPATHに追加されていない

### まず試してください

1. **PCを再起動**する（これだけで解決するケースが多いです）
2. 再起動後、コマンドプロンプトを開く

   ::: details コマンドプロンプトの開き方
   「スタート」ボタンをクリック → 検索欄に「cmd」と入力 → Enter を押す
   :::

3. 次のコマンドを入力して Enter を押す：
   ```
   latex --version
   ```
4. TeX Live のバージョン番号が表示されれば成功

<!-- TODO(media): コマンドプロンプトを開いてlatex --versionを実行する操作 -->

### 解決しない場合

再起動してもコマンドが認識されない場合、PATHの手動確認が必要です。

1. コマンドプロンプトで次を入力する：
   ```
   where latex
   ```
2. 何も表示されない場合は、TeX Live が正しくインストールされていない可能性がある
3. TeX Live のインストールをやり直すことを検討する
