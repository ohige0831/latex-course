# Windows トラブルシューティング

環境構築でつまったときは、症状に近いカテゴリを開いてください。

---

## カテゴリから探す

| カテゴリ | こんな症状に |
|---|---|
| [TeX Live](./texlive) | インストーラーが起動しない・`latex` コマンドが見つからない |
| [VS Code](./vscode) | 拡張機能が表示されない・settings.json がおかしい |
| [コンパイル](./compile) | PDFが生成されない・Recipe terminated・Undefined control sequence |
| [PDF表示](./pdf) | プレビューが開かない・PDFが更新されない・真っ白になる |
| [日本語](./japanese) | 文字化け・日本語ファイル名のエラー |
| [よくあるミス](./common-mistakes) | 拡張子が .txt・フォルダー名の問題・OneDrive |

---

## エラーメッセージの見つけ方

VS Code でコンパイルに失敗したとき、エラーの詳細は **OUTPUTタブ** に表示されます。

<!-- TODO(media): OUTPUTタブを開いてLaTeX Workshopを選択する操作 -->

1. VS Code の画面下部にある **「OUTPUT」** タブをクリックする
2. 右側のドロップダウンから **「LaTeX Workshop」** を選択する
3. 表示されたテキストの**末尾付近**を見る

::: tip どこを見ればよいか
`!` または `Error:` で始まる行を探してください。その直後に原因が書かれていることが多いです。テキスト全体を読む必要はありません。
:::

---

## 質問するときに伝えること

問題が解決しない場合、AI や先輩に相談するときに以下を共有すると早く解決します。

- **OUTPUTタブのテキスト**（LaTeX Workshop を選択した状態でコピー）
- **使用した `.tex` ファイルの内容**
- **`settings.json` の内容**
- **画面全体のスクリーンショット**
