## 日本語が文字化けする・豆腐（□）になる

### 症状

PDF を開いたとき、日本語の部分が文字化けしている、または □（豆腐）の記号だらけになる。

### 考えられる原因

- LuaLaTeX ではなく pdfLaTeX でコンパイルされている
- `.tex` ファイルの文字コードが UTF-8 でない
- `jlreq` ではなく英語向けの `article` などを使っている

### まず試してください

1. **コンパイルに使われているエンジンを確認する**  
   OUTPUTタブ（LaTeX Workshop）の先頭付近に `This is LuaHBTeX` と書かれているか確認する。  
   `This is pdfTeX` や `This is XeTeX` と書かれていたら、LuaLaTeX が使われていない

   <!-- TODO(media): OUTPUTタブでLuaHBTeXと表示されていることを確認する操作 -->

2. LuaLaTeX になっていない場合、settings.json を確認する  
   （[→ LaTeX Workshop の設定](/02-installation/windows/latex-workshop)）

3. **ファイルの文字コードを確認する**  
   VS Code の右下に「**UTF-8**」と表示されているか確認する

   <!-- TODO(media): VS Code右下の文字コード表示を確認する操作 -->

4. 「UTF-8」でない場合：右下の文字コード表示をクリック → 「エンコード付きで保存」→「UTF-8」を選ぶ

5. `.tex` ファイルの1行目を確認する。`\documentclass{jlreq}` になっているか確認する

   ```latex
   \documentclass{jlreq}   ← これが必要
   \begin{document}
   日本語テスト
   \end{document}
   ```

### 解決しない場合

`jlreq` に加えて `luatexja` パッケージを `\usepackage{luatexja}` で読み込んでも解決しない場合は、TeX Live のインストールが不完全な可能性があります。TeX Live の再インストールを検討してください。

## 日本語のファイル名・フォルダー名でエラーになる

### 症状

`.tex` ファイルのファイル名やフォルダー名に日本語（または全角文字）が含まれているとコンパイルがエラーになる。OUTPUTタブに文字化けしたパスが表示されている。

### 考えられる原因

- LaTeX のエンジンが日本語のファイルパスを正しく扱えない
- Windows のパス処理と LaTeX の相性問題

### まず試してください

1. `.tex` ファイルを置いているフォルダーのパス（場所）を確認する  
   例：`C:\Users\田中太郎\Documents\論文\main.tex`

2. フォルダー名とファイル名に**英数字・ハイフン・アンダースコアのみ**を使う場所に移す  
   例：`C:\Users\tanaka\Documents\latex-work\main.tex`

3. フォルダーを移動したら VS Code でそのフォルダーを開き直す（「ファイル」→「フォルダーを開く」）

4. 再コンパイルする

::: warning 「デスクトップ」に置かない
デスクトップのフルパスは `C:\Users\ユーザー名\Desktop` です。ユーザー名に日本語が含まれている場合は問題が起きることがあります。`C:\latex-work` のようなシンプルなパスを使うことをおすすめします。
:::

### 解決しない場合

以下のパスがすべて ASCII 文字のみになっているか確認してください。

- ユーザー名（`C:\Users\????`）
- フォルダー名
- ファイル名（`.tex` の拡張子のみ、本体は英数字）

ユーザー名に日本語が含まれている場合、`C:\latex` のようにドライブ直下にフォルダーを作ると回避できます。
