# よくある初心者のミス

環境構築・コンパイル問題の原因の多くは、LaTeXそのものではなくファイルや設定の基本的なミスです。まずここを確認してください。

---

## ファイル拡張子が `.txt` になっている

### 症状

ファイルを保存したのに VS Code でLaTeXとして認識されない。または `.tex` ファイルのつもりが、実際には `main.tex.txt` というファイルになっている。

### 考えられる原因

- Windows は初期設定で拡張子を非表示にしている
- テキストエディタで保存したときに `.txt` が自動的についた

### まず試してください

1. **エクスプローラーで拡張子を表示する**  
   エクスプローラーを開く → 上部メニューの「表示」→「ファイル名拡張子」にチェックを入れる

   <!-- TODO(media): エクスプローラーで拡張子を表示する設定をオンにする操作 -->

2. ファイルの名前を確認する。`main.tex` ではなく `main.tex.txt` や `main.txt` になっていたら、F2キーで名前を変更して `.tex` に修正する

3. VS Code で `.tex` ファイルを開き直す

::: warning ファイルの種類の確認
エクスプローラーのファイルアイコンが「メモ帳のアイコン」になっていたら、テキストファイルです。VS Code のアイコンや LaTeX のアイコンになっていることを確認してください。
:::

### 解決しない場合

VS Code でファイルを新規作成するときは、ファイル名の入力欄に `main.tex` と**拡張子まで含めて入力**してください。

## フォルダー名・ファイル名に特殊文字やスペースがある

### 症状

コンパイルするとエラーが出る。またはコンパイルが始まらない。ファイルパスに空白や記号が含まれている。

### 考えられる原因

- LaTeX はファイルパスに含まれるスペースや特殊文字（`#` `%` `&` など）を正しく扱えないことがある
- 日本語フォルダー名も同様の問題を引き起こす

### まず試してください

1. 作業フォルダーのパスを確認する（例：`C:\Users\田中\Desktop\卒業論文 2026\main.tex`）
2. 次のルールに当てはまるものがあれば修正する：

   | 使わないほうがよいもの | 代替案 |
   |---|---|
   | スペース（`my document`） | ハイフンやアンダースコア（`my-document`） |
   | 日本語（`論文`） | 英数字（`thesis`） |
   | 特殊文字（`#`, `%`, `&`, `(`, `)`） | 使わない |
   | 長いパス（260文字超） | より上のフォルダーに移動 |

3. 例えば、`C:\latex-work\main.tex` のようなシンプルな場所に移動する

4. VS Code でフォルダーを開き直す

## OneDriveと同期しているフォルダーで問題が起きる

### 症状

コンパイル中にエラーになる、または PDF が生成されない。ファイルのアイコンにクラウドマークや同期マークが表示されている。

### 考えられる原因

- OneDrive がファイルを同期しようとして「ファイルをロック」している
- コンパイル中に LaTeX が書き込もうとしたファイルを OneDrive が別プロセスで使っている
- OneDriveのパスに日本語（ユーザー名など）が含まれている

### まず試してください

1. **作業フォルダーを OneDrive の外に移動する**  
   例：`C:\latex-work` のようにドライブ直下や `Documents` でない場所に置く

2. OneDrive のフォルダーかどうかの確認：  
   フォルダーのパスに `OneDrive` という文字が含まれていれば対象です  
   例：`C:\Users\tanaka\OneDrive\ドキュメント\...` → OneDrive管理下

3. 移動後、VS Code でそのフォルダーを開き直す

::: tip OneDriveを使いたい場合
作業が終わった後、完成したファイルを手動でOneDriveフォルダーにコピーするのがおすすめです。作業中は OneDrive 外のフォルダーで行いましょう。
:::

### 解決しない場合

OneDrive のタスクトレイアイコン（通知領域）を右クリック →「同期の一時停止」で同期を止めてからコンパイルすると改善する場合があります。

## 全角スペースが混入している

### 症状

`.tex` ファイルにエラーはないはずなのに、特定の場所でコンパイルエラーになる。エラーの原因が一見わからない。

### 考えられる原因

- 日本語入力に切り替えたときに、誤って**全角スペース（　）**がコマンドや記号の部分に入った
- 全角スペースは半角スペースと見た目が似ており、気づきにくい

### まず試してください

1. VS Code でエラーが出ている行付近を確認する
2. 検索機能（`Ctrl + H`）で全角スペース（　）を探す  
   検索欄に全角スペースを直接入力して検索する

3. LaTeX コマンド（`\begin`, `\end`, `\documentclass` など）の前後に全角スペースがないか確認する

4. 全角スペースを半角スペースに置換する

::: tip 予防策
LaTeXファイルを編集するときは、コマンドを書く前に日本語入力（IME）を確実にオフ（英数字モード）にしてください。ステータスバーに「A」と表示されていれば英数字モードです。
:::
