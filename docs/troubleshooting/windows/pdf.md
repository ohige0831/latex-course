# PDF表示のトラブル

---

## PDFプレビューが開かない

### 症状

コンパイルは終わったようなのに、PDF が VS Code 内に表示されない。

### 考えられる原因

- コンパイルに失敗していて PDF ファイルが存在しない
- PDFビューワーの表示方法が変わっている

### まず試してください

1. まずコンパイルが成功しているか確認する。VS Code の右下に「Recipe terminated with error」と表示されていたら、コンパイル失敗なので[→ コンパイルのトラブル](./compile)を先に確認する

2. コンパイルが成功している場合、VS Code のエクスプローラー（左パネル）で `.tex` ファイルと同じフォルダーに `.pdf` ファイルが生成されているか確認する

3. PDF が存在する場合は、LaTeX Workshop のメニューから手動で開く：
   - 画面左の TeX アイコンをクリック
   - 「View LaTeX PDF」をクリック

4. または VS Code 右上のアイコン（虫眼鏡マーク）をクリックする

<!-- TODO(media): VS Code右上のPDF表示ボタンをクリックする操作 -->

### 解決しない場合

- `.pdf` ファイルをエクスプローラー（VS Code の左パネル）で右クリック → 「既定のプログラムで開く」を選んでWindowsのPDFビューワーで開く
- それで開ければ PDF は正常に生成されている。VS Code 内のプレビューの問題なので、LaTeX Workshop を再インストールする

## PDFが更新されない

### 症状

`.tex` を修正して保存・コンパイルしたが、PDF の表示内容が変わらない。

### 考えられる原因

- 外部のPDFビューワー（Adobe Acrobat など）が PDF を開いたまま「ファイルをロック」している
- VS Code 内のPDFビューワーのキャッシュ

### まず試してください

1. **外部のPDFビューワーを閉じる**（Adobe Acrobat、Adobe Reader、ブラウザで開いている場合も含む）
2. VS Code 内の PDF タブも一度閉じる
3. もう一度コンパイルして、PDF タブを開き直す

::: tip 外部ビューワーを使わない
VS Code に内蔵されている PDF ビューワーを使うと、コンパイルのたびに自動更新されるため便利です。
:::

### 解決しない場合

コマンドプロンプトで PDF ファイルと同じフォルダーを開き、`.pdf` ファイルを削除してから再コンパイルすると解決することがあります。

## PDFが真っ白になる

### 症状

PDF は開けるが、何も書かれていない（白紙になっている）。

### 考えられる原因

- `.tex` ファイルの `\begin{document}` と `\end{document}` の間に何も書かれていない
- コンパイルエラーが起きているが PDF ファイルだけが残っている（前回成功した PDF）

### まず試してください

1. `.tex` ファイルを開いて、内容を確認する
2. `\begin{document}` と `\end{document}` の**間**に本文が書かれているか確認する
3. 次のサンプルを参考に、最低限の内容があるか確認する：

   ```latex
   \documentclass{jlreq}
   \begin{document}
   
   ここに文章を書きます。
   
   \end{document}
   ```

4. OUTPUTタブ（LaTeX Workshop）を開いてエラーがないか確認する

### 解決しない場合

- PDF を削除してから再コンパイルする（古い PDF が残っている可能性）
- `\documentclass` の行が `jlreq` や他の有効な文書クラスになっているか確認する
