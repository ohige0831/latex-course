## LaTeXとは何か

LaTeX（ラテフ、またはラテックス）は、**文書を「組版」するためのシステム**です。

「組版」とは、文字や図を紙面に美しく配置する作業のことです。書籍・論文・学術雑誌などは、専門の組版職人が版を組んで印刷していました。LaTeXはそれをコンピュータ上で自動化したものです。

LaTeXを使うときは、Word のように画面上で見た目を整えるのではなく、**テキストファイルに文章と命令を書いて、それをコンパイル（変換）してPDFを生成します**。

```latex
\documentclass{jlreq}
\begin{document}
こんにちは、\LaTeX！
\end{document}
```

このような `.tex` ファイルをコンパイルすると、整形されたPDFが出力されます。

## なぜ研究の現場でLaTeXが使われるのか

### 数式が美しく書ける

理工系の論文には複雑な数式が欠かせません。LaTeXは数式組版において世界標準です。

```latex
\[
  E = mc^2
\]
```

```latex
\[
  \int_{-\infty}^{\infty} e^{-x^2} \, dx = \sqrt{\pi}
\]
```

このような複雑な数式も、コードとして正確に記述できます。

### 参考文献・引用が自動管理できる

論文では参考文献の管理が大変です。LaTeXは文献管理ツール（BibTeXやBibLaTeX）と組み合わせることで、引用番号の振り直しや文献リストの整形を自動化できます。

### 体裁が崩れない

Wordでは図を挿入したり長文を書いたりするとレイアウトが崩れることがあります。LaTeXはコマンドで構造を定義するため、体裁が崩れにくく、最終的なPDFの品質が安定しています。

### 学術誌・学会が対応している

多くの国際学術誌や学会がLaTeXのテンプレートを配布しており、投稿規定でLaTeXを指定していることもあります。

## WordとLaTeXの違い

| 観点 | Word | LaTeX |
|---|---|---|
| 操作方式 | 見たままを編集（WYSIWYG） | コードを書いてコンパイル |
| 数式 | 書けるが崩れやすい | 美しく正確に書ける |
| レイアウト | 自分で整える | 自動で整形される |
| ファイル形式 | .docx（バイナリ） | .tex（テキスト） |
| バージョン管理 | 向いていない | Gitと相性がよい |
| 習得難度 | 低い | 最初は高め |

LaTeXは最初の習得に時間がかかりますが、一度覚えると**複雑な文書を効率よく、品質高く**作れます。

## この講座で使う環境

この講座では **LuaLaTeX** というエンジンを使います。

LaTeXには歴史的な経緯から複数の「エンジン（処理系）」が存在します。主なものは以下の通りです。

| エンジン | 特徴 |
|---|---|
| pdfLaTeX | 古くからある定番。欧文に強い |
| XeLaTeX | OpenTypeフォントが使えるなど機能が豊富 |
| LuaLaTeX | 最新世代。日本語対応が優れており今後の標準 |

LuaLaTeXは日本語文書への対応が優れており、最新の文書クラス（jlreqなど）と組み合わせると少ない設定で日本語文書を作成できます。

::: tip
古い文書やウェブ上の情報では、日本語LaTeXとして **pLaTeX** や **upLaTeX** が紹介されていることがあります。これらは動作しますが、今から学ぶ場合は **LuaLaTeX** を使うことをおすすめします。
:::
