# 動作確認

## このページでできること

- テスト用のLaTeXファイルを作成してコンパイルする
- PDFが正しく生成されることを確認する

---

## テスト用ファイルの作成

1. VS Codeで **「ファイル」→「新しいフォルダーを開く」** から、作業用のフォルダー（例：`Documents\latex-test`）を作成して開く

<!-- TODO(media): VS Codeで新しいフォルダーを作成して開く操作 -->

2. エクスプローラー（左側のパネル）で **「新しいファイル」** アイコンをクリックし、ファイル名を `test.tex` として作成する

<!-- TODO(media): test.texファイルを新規作成する操作 -->

3. `test.tex` に次の内容をそのまま入力（またはコピー&ペースト）する：

```latex
\documentclass{jlreq}
\begin{document}

こんにちは、\LaTeX！

\[
  E = mc^2
\]

\end{document}
```

::: tip jlreqとは
`jlreq` は、日本語文書向けの文書クラスです。LuaLaTeXと組み合わせると、日本語を含む文書を追加設定なしに作成できます。
:::

---

## コンパイルの実行

1. `test.tex` を開いた状態で `Ctrl + S` を押してファイルを保存する
2. ファイルを保存すると、LaTeX Workshopが自動的にコンパイルを開始します

<!-- TODO(media): test.texを保存してコンパイルが始まる様子 -->

3. VS Codeの下部にあるステータスバーに進捗が表示されます。しばらく待つとコンパイルが完了します

::: tip 初回は少し時間がかかる
TeX Liveが必要なファイルを初回ロードするため、最初のコンパイルは1〜2分かかることがあります。2回目以降は速くなります。
:::

---

## PDFの確認

コンパイルが成功すると、同じフォルダーに `test.pdf` が生成されます。

1. VS Codeの右上に **「View in PDF viewer」** ボタン（虫眼鏡のアイコン）が表示されるのでクリックする
2. または、LaTeX Workshopのメニューから「View LaTeX PDF」を選択する

<!-- TODO(media): PDFビューワーでtest.pdfを表示する操作 -->

PDFに「こんにちは、LaTeX！」という文字と `E = mc²` という数式が表示されていれば成功です。

## よくある問題

**コンパイルが終わらない、またはエラーが出る**  
→ VS Codeの下部「OUTPUT」タブでエラーメッセージを確認し、[Windows固有のトラブルシューティング](/troubleshooting/windows/) を参照してください。

**PDFが真っ白または文字化けしている**  
→ `jlreq` が正しく読み込まれていない可能性があります。TeX Liveのインストールが完了しているか確認してください。

**「Recipe terminated with error」と表示された**  
→ `settings.json` のLuaLaTeX設定を再確認してください。特にカンマの付け忘れや大文字・小文字のミスがないか確認します。
