# Windows環境構築：準備と全体像

## このページでわかること

- Windows上にLaTeX環境を構築するために何をインストールするのか
- 全体の手順の流れと所要時間の目安

---

## 必要なもの

| ソフトウェア | 役割 |
|---|---|
| **TeX Live** | LaTeXのエンジンやパッケージ一式 |
| **Visual Studio Code** | ソースコードを編集するエディタ |
| **LaTeX Workshop** | VS Code上でLaTeXをコンパイルする拡張機能 |

これら3つを順番にインストールします。

## 所要時間の目安

| 作業 | 時間 |
|---|---|
| TeX Liveのダウンロードとインストール | 30〜90分（通信速度・PCの速度による） |
| VS Codeのインストール | 5〜10分 |
| LaTeX Workshopの設定 | 10〜15分 |
| 動作確認 | 5〜10分 |

**合計：1〜2時間程度。**  
TeX Liveのインストールは特に時間がかかります。インストール中は他の作業をしながら待てます。

---

## 全体の手順

以下の順番で進めてください。

1. [TeX Liveのインストール](./texlive) — LaTeX本体
2. [VS Codeのセットアップ](./vscode) — エディタ
3. [LaTeX Workshopの設定](./latex-workshop) — 拡張機能とLuaLaTeX設定
4. [動作確認](./verify) — テスト文書のコンパイル

---

## 注意事項

- **インストール先はデフォルトのまま**にすることを推奨します。自己判断で変更するとエラーの原因になることがあります。
- **インターネット接続が必要**です。TeX Liveは数GBのダウンロードが発生します。
- 途中でエラーが出た場合は [トラブルシューティング](/troubleshooting/windows/) を参照してください。
