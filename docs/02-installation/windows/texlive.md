# TeX Liveのインストール

## このページでできること

- TeX Liveをダウンロードし、Windowsにインストールする
- LaTeXのコンパイルに必要な一式を揃える

---

## TeX Liveとは

**TeX Live** は、LaTeXのエンジン・コマンド・スタイルファイル（パッケージ）を一括提供するディストリビューションです。Linux・macOS・Windowsに対応しており、国際的に広く使われています。

---

## ダウンロード

TeX LiveはTeX Users Group（TUG）の公式サイトから入手します。

1. ブラウザで [https://www.tug.org/texlive/](https://www.tug.org/texlive/) を開く
2. ページ内の **「download TeX Live」** または **「install TeX Live over the Internet」** のリンクを探す
3. Windowsのインストーラー（`install-tl-windows.bat` を含むzipファイル、またはインストーラーの直接リンク）をダウンロードする

::: tip ダウンロードに時間がかかる場合

TeX Liveの公式サイトの見た目や掲載リンクは更新のたびに変わることがあります。ページの構成が異なる場合は、「Windows」や「install」というキーワードで探してください。

## インストール

1. ダウンロードしたファイルを展開し、`install-tl-windows.bat` をダブルクリックして実行する

## インストールの確認

コマンドプロンプト（またはPowerShell）を開いて、次のコマンドを入力してください。

```
latex --version
```

「TeX Live」の文字とバージョン番号が表示されれば成功です。

## よくある問題

**インストーラーが「管理者権限が必要」と表示された**  
→ インストーラーを右クリックして「管理者として実行」を選んでください。

**インストール中にエラーが出た**  
→ エラーメッセージをコピーして [Windows固有のトラブルシューティング](/troubleshooting/windows/) を参照してください。

**`latex --version` で「コマンドが見つかりません」と表示された**  
→ インストール後にPCを再起動してから再度試してください。それでも解決しない場合は [トラブルシューティング](/troubleshooting/windows/) を参照してください。
