## VS Codeとは

**Visual Studio Code**（VS Code）は、Microsoftが開発する無料のコードエディタです。LaTeXに限らず、多くのプログラミング言語や文書フォーマットに対応しており、拡張機能を追加することで機能を広げられます。

この講座では、VS Codeに **LaTeX Workshop** という拡張機能を追加して、LaTeXの編集とコンパイルを行います。

## 日本語化（任意）

VS Codeのインターフェースを日本語にしたい場合は、次の手順で言語パックを導入できます。

1. VS Codeを起動する
2. 左側のアイコンバーから **拡張機能**（四角いアイコン）をクリックする
3. 検索欄に「Japanese Language Pack」と入力する
4. 「Japanese Language Pack for Visual Studio Code」（Microsoftが提供）をインストールする
5. 再起動を促すメッセージが表示されたら、再起動する
