# はじめに

## この教材について

この教材は、研究室に配属された学生が **LaTeXを使った文書作成を自力でできるようになること** を目標としています。

先輩に逐一質問しなくても環境を整え、レポートや論文の下書きを作れる状態になるまで、ステップごとに案内します。

LaTeXをまったく触ったことがなくても、PCを普通に使えれば問題ありません。プログラミングの知識は不要です。

## 対象読者

- LaTeXをはじめて使う大学生・大学院生
- 研究室に新しく配属された方
- 指導教員や先輩から「LaTeXでレポートを書くように」と言われた方

## 推奨環境

この教材は以下の環境を前提としています。

| ソフトウェア | 内容 |
|---|---|
| **OS** | Windows 11 |
| **LaTeXディストリビューション** | TeX Live（最新版） |
| **エディタ** | Visual Studio Code |
| **エディタ拡張** | LaTeX Workshop |
| **LaTeXエンジン** | LuaLaTeX |

macOS・Linux・Overleafは現在準備中です。

### なぜLuaLaTeXを使うのか

この教材では、LaTeXのエンジンとして **LuaLaTeX** を使います。LuaLaTeXは日本語文書への対応が優れており、追加パッケージを大量に入れなくても日本語を扱えます。研究室でも広く使われているため、トラブル時に相談しやすい環境です。

## この教材の使い方

1. **はじめから順番に読む**のが基本です。特に環境構築は順番に進めてください。
2. 各ページの冒頭に「このページでできるようになること」を書いています。まずそこを読んでから本文に進んでください。
3. 各ページの末尾に「ここまでできればOK」があります。そこを確認してから次のページへ進んでください。
4. 環境構築が終わったら、第3章「はじめての文書」から実際にLaTeXを使い始められます。

## 困ったときは

操作中に問題が起きたときは、まず [トラブルシューティング](/troubleshooting/) を確認してください。よくあるエラーの対処方法をまとめています。

それでも解決しない場合は、エラーメッセージをそのままコピーして先輩や指導教員に見せてください。エラーメッセージには問題の手がかりが含まれています。

## バージョン情報

本教材は **2026年7月時点** の情報をもとに作成しています。TeX Live・Visual Studio Code・LaTeX Workshopはいずれも更新が行われるため、画面の表示や操作手順が一部異なる場合があります。手順が大きく変わっていると感じたときは、各ソフトウェアの公式ドキュメントも参照してください。
